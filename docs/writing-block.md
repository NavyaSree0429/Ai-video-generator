# 1. INTRODUCTION

## 1.1 Purpose

The purpose of this Software Requirements Specification (SRS) document is to define the functional and non-functional requirements of the proposed AI Video Studio & Instagram Auto Publisher application.

This application will allow a user to generate videos using text prompts or uploaded images, edit the generated videos, create captions and hashtags, and publish or schedule videos on Instagram.

The application will integrate free cloud-based AI services to generate videos without requiring users to install or run AI models on their personal computers.

This document establishes the requirements that will guide the design, development, implementation and testing of the application.

## 1.2 Project Overview

AI Video Studio & Instagram Auto Publisher is an AI-powered web application designed to automate the video creation and social media publishing process.

Users can enter a text prompt or upload an image. The application will process the input through an available free AI video-generation provider and generate a video.

After generation, users can preview and edit the video, add voiceovers, subtitles, background music and text, and generate suitable captions and hashtags.

Finally, users can publish the video immediately or schedule it for future publication through the official Instagram API, subject to Meta's account eligibility and permissions.

## 1.3 Problem Statement

Creating and publishing videos for social media platforms involves several time-consuming activities.

Content creators generally need separate tools for:

- Writing video scripts.
- Generating images and videos.
- Editing videos.
- Adding voiceovers and subtitles.
- Creating captions and hashtags.
- Designing thumbnails.
- Publishing and scheduling content.

Managing these activities through multiple applications increases the time and effort required to create social media content.

Therefore, this project proposes an integrated AI-powered web application that combines video generation, editing and Instagram publishing into one platform.

The system aims to simplify the complete video creation workflow through a single interface.

## 1.4 Proposed Solution

The proposed application will provide the following solution:

1. Accept text prompts and image uploads.
2. Generate videos using available free cloud AI models.
3. Support short and long video creation through scene-based generation when required.
4. Support Telugu and English content.
5. Provide video editing functionality.
6. Generate AI-based captions and hashtags.
7. Connect one Instagram Creator account.
8. Support manual and automatic publishing.
9. Allow users to schedule Instagram posts.
10. Maintain a history of generated and published videos.

- Save prompts.

# 5. FUNCTIONAL REQUIREMENTS

Functional requirements describe what the system must do.

## FR-01: User Registration

The system shall allow a user to create an account using their name, email address and password.

## FR-02: User Login

The system shall authenticate registered users using their login credentials.

## FR-03: Dashboard

The system shall display a dashboard containing:

- Total projects.
- Generated videos.
- Draft videos.
- Published videos.
- Scheduled videos.
- Recent activity.

## FR-04: Text-to-Video Generation

The system shall allow users to enter a text prompt and generate a video using an available compatible free AI service.

Example prompt:

"Create a cinematic video showing Lord Shiva meditating in the Himalayas with beautiful mountains and a peaceful atmosphere."

## FR-05: Image-to-Video Generation

The system shall allow users to upload an image and provide an optional prompt describing the desired animation.

The system shall send the input to a compatible free image-to-video service.

## FR-06: Video Configuration

The system shall allow users to configure:

- Video generation method.
- Duration.
- Language.
- Aspect ratio.
- Video description.
- Other settings supported by the selected model.

## FR-07: Video Generation Progress

The system shall display the status of video generation.

Possible statuses:

- Pending.
- Processing.
- Completed.
- Failed.
- Cancelled.

## FR-08: Provider Fallback

The system shall check provider availability and quota before submitting generation requests.

If a provider is unavailable, the system shall attempt another compatible provider that has verified free access.

The system shall never switch to a paid provider automatically.

If all free providers are unavailable, the system shall notify the user.

## FR-09: Video Editing

The system shall allow users to edit generated videos before publishing.

Editing operations shall include trimming, cropping, merging, text addition, audio addition and subtitle addition.

## FR-10: Voiceover

The system should support voiceover generation in Telugu and English through compatible free text-to-speech services.

## FR-11: Caption Generation

The system shall allow users to generate captions based on video prompts or descriptions.

Users shall be able to edit generated captions manually.

## FR-12: Hashtag Generation

The system shall generate relevant hashtags based on the video's topic.

Users shall be able to add or remove hashtags.

## FR-13: Thumbnail Generation

The system should provide thumbnail creation using available free image-generation services or video-frame extraction.

## FR-14: Project Saving

The system shall save video projects, prompts, generation settings and media references.

## FR-15: Instagram Account Connection

The system shall allow users to connect one eligible Instagram Creator account through the supported official Meta authentication process.

## FR-16: Manual Publishing

The system shall allow users to preview the final video and manually initiate publishing.

## FR-17: Automatic Publishing

The system shall support an optional automatic publishing mode.

Automatic publishing shall only occur after the user explicitly enables the feature and configures the required publishing preferences.

## FR-18: Scheduled Publishing

The system shall allow users to select a future publishing date and time.

The backend scheduling service shall execute eligible publishing tasks.

## FR-19: Publishing Status

The system shall display publishing results.

Possible statuses:

- Draft.
- Scheduled.
- Publishing.
- Published.
- Failed.

## FR-20: Video History

The system shall maintain a history of generated and published videos.

## FR-21: Notifications

The system should notify users about:

- Successful video generation.
- Failed generation.
- Completed video editing.
- Successful Instagram publishing.
- Failed Instagram publishing.
- Upcoming scheduled posts.

## FR-22: Provider Usage Monitoring

The system shall maintain information about provider availability, quota usage, errors and free-tier restrictions.

# 6. NON-FUNCTIONAL REQUIREMENTS

Non-functional requirements define how the system should perform.

## 6.1 Performance

- The application should load its main interface efficiently.
- Video generation shall run as a background task.
- Users should be able to monitor generation progress.
- Heavy video processing should not block normal API requests.

## 6.2 Security

- Passwords shall be securely hashed.
- Authentication shall be implemented using secure tokens.
- API credentials shall not be exposed in frontend code.
- Instagram access tokens shall be securely protected.
- User projects shall only be accessible to their authorized owner.
- Uploaded files shall be validated.

## 6.3 Reliability

- The system shall handle temporary AI provider failures.
- Failed tasks should provide understandable error messages.
- The system shall support safe retry mechanisms.
- Publishing tasks should avoid duplicate submissions.

## 6.4 Usability

- The interface shall be simple and user-friendly.
- Navigation shall be clear.
- Video generation status shall be visible.
- Users shall be able to preview videos before publishing.

## 6.5 Maintainability

- Frontend and backend code shall be organized separately.
- AI providers shall be integrated through separate adapters.
- API routes and business logic shall be separated.
- The application shall support future feature additions.

## 6.6 Cost Efficiency

- Only free AI services shall be used.
- The system shall check free usage limits.
- Paid providers shall be disabled by default.
- The system shall never automatically charge the user.
- If free quota is exhausted, generation shall stop until an eligible free option becomes available.

## 6.7 Compatibility

The application should support modern browsers, including:

- Google Chrome.
- Microsoft Edge.
- Mozilla Firefox.

The application should use responsive design for desktop, tablet and mobile screens.

# 7. SYSTEM WORKFLOW

The overall application workflow is as follows:

### Step 1: Login

The user logs in to the application.

### Step 2: Create a Project

The user selects Create New Video.

### Step 3: Choose Generation Method

The user selects one of the following:

- Text-to-Video.
- Image-to-Video.

### Step 4: Enter Input

For text-to-video, the user enters a prompt.

For image-to-video, the user uploads an image and enters an optional animation prompt.

### Step 5: Configure Video

The user selects duration, language and aspect ratio.

### Step 6: AI Processing

The backend checks available free AI providers and submits the generation request.

### Step 7: Video Generation

The AI service generates the video.

For long videos, multiple scenes may be generated and combined.

### Step 8: Video Editing

The user previews and edits the generated video.

### Step 9: Caption and Hashtag Generation

The application generates a caption and relevant hashtags.

### Step 10: Instagram Publishing

The user selects:

- Publish Now.
- Schedule Post.
- Enable Automatic Publishing.

### Step 11: Publishing Status

The application displays the publishing result and stores the post details.

# 9. SYSTEM CONSTRAINTS AND LIMITATIONS

## 9.1 Free AI Service Limitations

Free cloud AI services may have:

- Daily or monthly generation limits.
- Queue restrictions.
- Model availability changes.
- Request timeouts.
- File-size restrictions.
- Limited video duration.
- Temporary service unavailability.

The application cannot guarantee unlimited generation.

## 9.2 Long Video Generation

Long videos may require multiple AI generation requests.

The application shall divide long content into scenes and combine the generated scenes using FFmpeg.

## 9.3 Language Limitations

Telugu and English support will depend on the capabilities of the selected models.

Telugu prompt translation may be used when a video model performs better with English prompts.

Generated Telugu narration and subtitles must be checked for language accuracy.

## 9.4 Instagram Limitations

Instagram publishing depends on:

- Eligible account type.
- Meta app configuration.
- User authorization.
- Required permissions.
- Media requirements.
- API rate limits.
- Supported publishing formats.

The system cannot guarantee publishing if Meta rejects the request or the connected account becomes ineligible.

## 9.5 Cloud Storage Limitations

Generated videos require storage.

Free cloud storage providers may restrict:

- Storage capacity.
- Bandwidth.
- File size.
- File retention.
- Public media access.

The system shall manage media according to the available free storage capacity.

## 9.6 Automatic Publishing Limitations

Automatic publishing requires a continuously available backend scheduler.

A scheduled post cannot be guaranteed if the application server or storage service is unavailable at the publishing time.
